Skill Share - Local LLM Model
==============================

DOWNLOAD THE MODEL (easiest way - from GitHub):
------------------------------------------------
Go to the GitHub releases page for Skill Share and download the
".gguf" model file listed under "Assets":

  https://github.com/indranilnnd-creator/Skill-Share/releases

Place the downloaded .gguf file in this "models" folder (or anywhere
on your computer). Then open index.html, click "Load Model", and
select the .gguf file.

ALTERNATIVE - download from Hugging Face (if accessible):
----------------------------------------------------------
Qwen2.5-3B-Instruct Q4_K_M (~1.9 GB, best quality):
https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/main/qwen2.5-3b-instruct-q4_k_m.gguf

Qwen2.5-1.5B-Instruct Q4_K_M (~1.0 GB, faster):
https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf

TinyLlama 1.1B Q4_K_M (~670 MB, fastest):
https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf

HOW TO USE:
-----------
1. Download ONE .gguf model file (see above)
2. Place it in this "models" folder, or anywhere you like
3. Open index.html in Edge/Chrome (double-click it)
4. Click "Load Model" in the top-right, then select the .gguf file
5. Wait for the progress to reach 100% ("Model ready")

NOTES:
------
- Qwen2.5 models are Apache-2.0 licensed (corporate-safe)
- For best quality use 3B; for speed/less RAM use 1.5B or TinyLlama
- The app runs fully offline; no data leaves your computer
