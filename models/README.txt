Skill Share - Local LLM Model
==============================

Download from Hugging Face:
https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/main/qwen2.5-3b-instruct-q4_k_m.gguf

Direct link (may work in browser):
https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/main/qwen2.5-3b-instruct-q4_k_m.gguf?download=true

ALTERNATIVE SMALLER MODELS (if 1.9 GB is too large):
-----------------------------------------------------
Qwen2.5-1.5B-Instruct Q4_K_M (~1.0 GB):
https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf

TinyLlama 1.1B Q4_K_M (~670 MB):
https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf

HOW TO USE:
-----------
1. Download ONE of the above .gguf files
2. Place it in this "models" folder (or anywhere on your computer)
3. Open index.html in Edge/Chrome
4. Click "Load Model" and select the .gguf file (or drag & drop it onto the page)
5. The app will remember the model location for next time

NOTES:
------
- The Qwen2.5-3B model is Apache-2.0 licensed (corporate-safe)
- For best quality, use Qwen2.5-3B; for speed/size, use 1.5B or TinyLlama
- Models larger than 2 GB require splitting (not needed for these)
- If Hugging Face is blocked on your work laptop, download the model on a personal device and copy the .gguf file here
